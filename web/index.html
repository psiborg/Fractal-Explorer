    About

    Fractal Explorer

    Explore the Mandelbrot, Burning Ship, Tricorn and Multibrot sets and their Julia sets, drawn live on your GPU.

    Built with

    • Rust for the app logic, compiled to WebAssembly with wasm-bindgen
    • wgpu 30, driving the browser's WebGPU API
    • WGSL shaders: one fragment shader per pixel, plus double-float maths for Deep zoom
    • Perturbation for very deep zoom: a 106-bit reference orbit on the CPU, per-pixel differences on the GPU
    • Vanilla HTML, CSS and JavaScript for the interface; works offline as a PWA

    This system

    Credits

    • The Mandelbrot set is named after Benoit Mandelbrot; Julia sets after Gaston Julia.
    • Double-float arithmetic follows T. J. Dekker (1971) and D. E. Knuth's TwoSum.
    • Colour palettes use Inigo Quilez's cosine-palette formula.
    • π at the neck of the set was found by Dave Boll (1991).
